Computer Basics - Lesson 1

Computer ka Introduction aur Basic Knowledge

📘 1. Computer Kya Hai?

Computer ek electronic device hai jo user se data leta hai, us data ko process karta hai aur result ke form mein useful information provide karta hai.

Simple language mein samjhein to computer ek aisi machine hai jo hamare diye hue instructions ke according kaam karti hai.

Simple Definition:

Computer ek electronic machine hai jo data ko accept, process, store aur output provide karti hai.

Example

Agar hum keyboard se 25 + 15 type karte hain, to computer is calculation ko process karega aur screen par result 40 dikhayega.

⚙️ 2. Computer Kaise Kaam Karta Hai?

Computer mainly chaar important steps mein kaam karta hai:

  1. Input - Computer ko data ya instruction dena.
  2. Processing - Computer data par calculation ya processing karta hai.
  3. Output - Processing ke baad result milta hai.
  4. Storage - Data ya result ko future ke liye save karna.
Example:

Keyboard se naam type karna → Input

Computer ka data process karna → Processing

Monitor par naam dikhna → Output

File mein naam save karna → Storage

🔢 3. Data Aur Information

Data kya hai?

Raw facts ya figures ko data kaha jata hai. Data apne original form mein ho sakta hai aur zaroori nahi ki uska direct meaning clear ho.

Example: 50, 70, 85, Aryan, Ahmedabad

Information kya hai?

Jab data ko process karke meaningful result milta hai, use information kaha jata hai.

Yaad Rakhein:

Data + Processing = Useful Information

💻 4. Computer Ke Main Parts

Computer ek single machine nahi hai. Iske kai different hardware parts milkar computer system banate hain.

🖥️ Monitor

Monitor ek output device hai. Is par computer ki information, pictures, videos, documents aur applications दिखाई deti hain.

⌨️ Keyboard

Keyboard ka use letters, numbers, symbols aur commands enter karne ke liye kiya jata hai.

🖱️ Mouse

Mouse ka use pointer ko control karne, files select karne, icons open karne aur different options par click karne ke liye kiya jata hai.

🧠 CPU

CPU ka full form Central Processing Unit hai. CPU computer ke processing work mein important role play karta hai.

🔊 Speakers

Speakers computer se audio aur sound sunne ke liye use hote hain.

🧩 5. Hardware Kya Hai?

Computer ke wo physical parts jinhe hum dekh aur touch kar sakte hain, hardware kehlate hain.

Hardware Examples:
  • Monitor
  • Keyboard
  • Mouse
  • CPU
  • Printer
  • Speaker
  • Hard Disk
  • Pen Drive

💿 6. Software Kya Hai?

Software instructions aur programs ka collection hota hai jo computer ko batata hai ki kya kaam karna hai.

Software ko hum normally touch nahi kar sakte. Hum ise computer par run ya use karte hain.

Software Examples:
  • Windows
  • Microsoft Word
  • Microsoft PowerPoint
  • Microsoft Excel
  • Web Browser
  • Media Player
Important:

Hardware ko aap touch kar sakte hain, lekin software ko physically touch nahi kar sakte.

⌨️ 7. Input Devices

Jin devices ki help se hum computer ko data ya instructions dete hain, unhe input devices kaha jata hai.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam
  • Joystick

🖥️ 8. Output Devices

Jin devices ke through computer hume processed result deta hai, unhe output devices kaha jata hai.

  • Monitor
  • Printer
  • Speakers
  • Projector
  • Headphones

💾 9. Memory Aur Storage

Computer mein data ko temporarily ya permanently store karne ke liye memory aur storage ka use hota hai.

RAM

RAM ka full form Random Access Memory hai. Ye computer ke working data ko temporarily hold karti hai.

Hard Disk

Hard Disk ka use files, documents, photos, videos aur software ko store karne ke liye kiya jata hai.

Pen Drive

Pen Drive ek portable storage device hai jise data ko ek computer se doosre computer mein transfer karne ke liye use kiya ja sakta hai.

📁 10. Files Aur Folders

File kya hai?

Computer mein kisi document, picture, video ya other data ko save kiya jaye to use file kaha jata hai.

Folder kya hai?

Folder ka use multiple files ko organized way mein rakhne ke liye kiya jata hai.

Example:

Ek folder ka naam My Study hai.

Iske andar English, Maths aur Computer ki files alag-alag rakhi ja sakti hain.

🌐 11. Computer Ka Use Kahan Hota Hai?

Aaj ke time mein computer ka use almost har field mein hota hai.

  • 🎓 Education
  • 🏢 Office Work
  • 🏦 Banking
  • 🏥 Hospitals
  • 🏪 Business
  • 🌐 Internet
  • 🎨 Designing
  • 🎮 Entertainment
  • 📊 Data Management
  • 🤖 Artificial Intelligence

✅ 12. Computer Ke Advantages

  • Computer bahut fast calculation kar sakta hai.
  • Large amount of data store kar sakta hai.
  • Repeated tasks ko efficiently perform kar sakta hai.
  • Education aur learning mein helpful hai.
  • Communication aur online services mein useful hai.
  • Office aur business work ko easier banata hai.

⚠️ 13. Computer Ki Limitations

  • Computer khud se normally decision nahi leta; instructions ki zaroorat hoti hai.
  • Electricity ya power source ki zaroorat hoti hai.
  • Wrong instructions se wrong result aa sakta hai.
  • Important data ko secure rakhna zaroori hai.

📝 14. Important Points

  • Computer ek electronic device hai.
  • Computer Input, Processing, Output aur Storage ke through kaam karta hai.
  • Keyboard ek input device hai.
  • Monitor ek output device hai.
  • CPU ka full form Central Processing Unit hai.
  • RAM ka full form Random Access Memory hai.
  • Hardware physical parts ko kaha jata hai.
  • Software programs aur instructions hote hain.
  • Files ko organize karne ke liye folders ka use hota hai.
