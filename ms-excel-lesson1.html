📈 MS Excel – Lesson 1

Introduction, Basic Operations, Formulas, Formatting & Exam Practice

1. MS Excel Kya Hai?

Microsoft Excel ek spreadsheet software hai jiska use data ko rows aur columns mein store, calculate, organize aur analyze karne ke liye kiya jata hai.

Simple Definition: Excel ek aisa software hai jisme hum data enter karke formulas ki madad se calculation kar sakte hain.

Excel ka use kahan hota hai?

  • Student Marksheet banane mein
  • Salary Statement banane mein
  • Attendance Sheet banane mein
  • Budget banane mein
  • Sales Report banane mein
  • Result calculate karne mein
  • Data analysis mein
  • Charts aur graphs banane mein

2. Workbook aur Worksheet

Workbook

Excel ki poori file ko Workbook kaha jata hai. Excel file ka extension aam taur par .xlsx hota hai.

Worksheet

Workbook ke andar jo individual sheet hoti hai use Worksheet kehte hain. Ek workbook mein multiple worksheets ho sakti hain.

Example:
Computer Siksha.xlsx = Workbook
Sheet1 = Worksheet
Sheet2 = Worksheet

3. Row, Column aur Cell

Row

Excel mein horizontal line ko Row kehte hain. Rows numbers se identify hoti hain: 1, 2, 3, 4...

Column

Excel mein vertical line ko Column kehte hain. Columns letters se identify hote hain: A, B, C, D...

Cell

Row aur Column ke intersection ko Cell kehte hain.

Example: Column B + Row 5 = Cell B5

5. Excel Formula Kya Hai?

Excel mein calculation karne ke liye formula ka use kiya jata hai. Excel mein formula aam taur par = sign se start hota hai.

=10+20

Result hoga: 30

Exam Point: Excel ka formula generally = sign se start hota hai.

6. Basic Mathematical Operators

Operator Meaning Example Result
+ Addition =10+5 15
- Subtraction =10-5 5
* Multiplication =10*5 50
/ Division =10/5 2
^ Power =2^3 8
Important: Excel mein multiplication ke liye × nahi, balki * use hota hai. Division ke liye / use hota hai.

7. Cell Reference ke Saath Formula

Excel ki sabse important baat hai ki hum cells ko reference karke calculation kar sakte hain.

Student Calculation
A B C
1 Student Marks 1 Marks 2
2 Aman 70 80

Total nikalne ke liye:

=B2+C2

Excel B2 aur C2 ki value ko add karega.

8. SUM Function

SUM function ka use numbers ko add karne ke liye hota hai.

=SUM(B2:B6)

Iska matlab B2 se B6 tak ki sabhi values ko add karna.

Example

Cell Marks
B270
B380
B475
B590
B685
=SUM(B2:B6)

Answer = 400

Exam Shortcut: AutoSum ke liye Alt + = use kar sakte hain.

9. AVERAGE Function

AVERAGE function numbers ka average nikalta hai.

=AVERAGE(B2:B6)

Agar marks 70, 80, 75, 90 aur 85 hain to average:

=(70+80+75+90+85)/5

Answer = 80

Excel mein direct formula:

=AVERAGE(B2:B6)

10. MAX Function

MAX function selected range mein sabse badi value find karta hai.

=MAX(B2:B6)

70, 80, 75, 90, 85 mein highest value 90 hai.

11. MIN Function

MIN function selected range mein sabse chhoti value find karta hai.

=MIN(B2:B6)

70, 80, 75, 90, 85 mein lowest value 70 hai.

12. COUNT Function

COUNT function selected range mein numerical values ki counting karta hai.

=COUNT(B2:B10)
Exam Point: COUNT mainly numbers ko count karta hai.

13. Percentage Calculation

Percentage marksheet aur exams mein bahut important hai.

Formula

=(Obtained Marks/Total Marks)*100

Example

Agar student ne 500 mein se 425 marks score kiye:

=(425/500)*100

Percentage = 85%

Excel mein

=(F2/G2)*100

Yahan F2 obtained marks aur G2 total marks ko represent kar sakta hai.

16. Merge & Center

Multiple cells ko ek cell jaisa combine karne ke liye Merge & Center ka use hota hai.

Example:

A1, B1, C1 aur D1 ko merge karke heading likh sakte hain:

STUDENT MARKSHEET
Marksheet ki heading banane mein Merge & Center ka use bahut useful hai.

17. Fill Handle

Excel mein ek formula ya series ko quickly neeche copy karne ke liye Fill Handle ka use kiya jata hai.

Example:

A1 = 1
A2 = 2
Dono cells ko select karke Fill Handle drag karne par:

3, 4, 5, 6, 7... automatically aa sakte hain.

Formula ko multiple students par apply karne ke liye bhi Fill Handle bahut useful hai.

18. Relative Cell Reference

Jab formula ko doosri cell mein copy karte hain aur cell references automatically change ho jate hain, ise Relative Reference kehte hain.

=B2+C2

Agar is formula ko next row mein copy karein to Excel ise automatically:

=B3+C3

kar dega.

19. Absolute Cell Reference – Basic Introduction

Kisi particular cell ko fixed rakhne ke liye $ sign ka use kiya jata hai.

=$B$2

Is reference ko formula copy karne par fixed cell reference ke roop mein use kiya ja sakta hai.

Lesson 2 mein is concept ka practical use salary calculation aur percentage calculation mein dekhenge.

20. Important Excel Functions – Exam Table

Function Use Example
SUM Total =SUM(B2:B10)
AVERAGE Average =AVERAGE(B2:B10)
MAX Highest Value =MAX(B2:B10)
MIN Lowest Value =MIN(B2:B10)
COUNT Numbers Count =COUNT(B2:B10)
Exam ke liye yaad rakhein:
SUM = Total
AVERAGE = Average
MAX = Maximum / Highest
MIN = Minimum / Lowest
COUNT = Number Counting

21. Excel mein Sorting ka Basic Concept

Sorting ka use data ko kisi order mein arrange karne ke liye hota hai.

  • A to Z – Alphabetical order
  • Z to A – Reverse alphabetical order
  • Smallest to Largest – Number order
  • Largest to Smallest – Reverse number order
Example:

Marks: 45, 90, 60, 75

Smallest to Largest:
45, 60, 75, 90

22. Excel mein Filter ka Basic Concept

Filter ka use large data mein se required information ko quickly display karne ke liye hota hai.

Example:

Agar marksheet mein 100 students hain aur sirf "Pass" students dekhne hain, to Filter ka use karke required records dekhe ja sakte hain.

Answer: =MAX(D2:D20)

Answer: =MIN(D2:D20)

Answer: =

Answer: *

Answer: /

Answer: Alt + =
Q11. File save karne ka shortcut?
Answer: Ctrl + S
Q12. Active cell edit karne ki key?
Answer: F2
Q13. Excel file ka common extension kya hai?
Answer: .xlsx
Q14. Row aur Column ke intersection ko kya kehte hain?
Answer: Cell
Q15. Workbook ke andar individual sheet ko kya kehte hain?
Answer: Worksheet
Q16. Sabse badi value find karne ke liye kaunsa function?
Answer: MAX
Q17. Sabse chhoti value find karne ke liye kaunsa function?
Answer: MIN

Answer: AVERAGE

Answer: Sorting

Answer: Filter
