2. PowerPoint Design Kya Hai?

Design ka use presentation ki appearance ko better banane ke liye kiya jata hai. Ek achha design presentation ko attractive aur easy to read banata hai.

Important: Design beautiful hone ke saath-saath readable bhi hona chahiye. Bahut zyada colors aur effects use karne se presentation confusing ho sakti hai.

3. Theme Kya Hoti Hai?

PowerPoint Theme colors, fonts aur overall visual style ka combination hoti hai. Theme apply karne se presentation ka look quickly change kiya ja sakta hai.

4. Theme Apply Kaise Karein?

  1. PowerPoint presentation open karein.
  2. Design tab par click karein.
  3. Themes section mein available themes dekhein.
  4. Apni pasand ki theme select karein.
  5. Theme presentation par apply ho jayegi.
Practical Tip: Education presentation ke liye simple aur readable theme choose karein.

6. Image Insert Karna

PowerPoint presentation mein images add karke information ko visually samjhaya ja sakta hai.

Steps:

  1. Insert tab par click karein.
  2. Pictures option select karein.
  3. Computer mein saved image choose karein.
  4. Insert par click karein.
  5. Image slide mein add ho jayegi.

7. Image ko Resize Kaise Karein?

Image insert karne ke baad uska size change kiya ja sakta hai.

  1. Image par click karein.
  2. Image ke corners par small handles दिखाई देंगे.
  3. Corner handle ko drag karein.
  4. Image ka size change ho jayega.
Tip: Image ko resize karte waqt corner se drag karna better hota hai, isse image ka proportion maintain rehne mein help milti hai.

8. Image ko Move Kaise Karein?

Image ko slide ke kisi bhi suitable location par move kiya ja sakta hai.

  1. Image select karein.
  2. Mouse pointer ko image ke andar le jayein.
  3. Mouse button press karke drag karein.
  4. Image ko desired position par place karein.

15. Transition Apply Kaise Karein?

  1. Jis slide par transition lagana hai usse select karein.
  2. Transitions tab open karein.
  3. Available transition effect select karein.
  4. Preview se effect check karein.
  5. Agar zarurat ho to duration set karein.
Tip: Professional presentation mein simple transitions ka use karna better hota hai.

16. Animation Kya Hai?

Animation ka use slide ke andar मौजूद text, image, shape ya other object par movement/effect dene ke liye kiya jata hai.

✨ Animation Example

17. Animation Apply Kaise Karein?

  1. Text ya object select karein.
  2. Animations tab open karein.
  3. Available animation effect choose karein.
  4. Preview karke result check karein.
  5. Timing ko zarurat ke according set karein.

18. Transition aur Animation mein Difference

Transition Animation
Ek slide se doosri slide ke change par effect. Slide ke andar object par effect.
Slide-level effect. Object-level effect.
Transitions tab se apply hota hai. Animations tab se apply hota hai.

21. Audio Add Karna

PowerPoint presentation mein audio add kiya ja sakta hai. Audio ka use narration, background sound ya explanation ke liye kiya ja sakta hai.

  1. Insert tab open karein.
  2. Audio option select karein.
  3. Required audio file choose karein.
  4. Audio presentation mein add ho jayega.
Audio use karte waqt presentation ke topic aur audience ka dhyan rakhein.

22. Video Add Karna

PowerPoint mein video bhi add kiya ja sakta hai. Educational presentations mein video explanation useful ho sakti hai.

  1. Insert tab open karein.
  2. Video option select karein.
  3. Required video choose karein.
  4. Video slide mein insert ho jayega.

23. Professional Slide Design ke Rules

  • Ek slide par bahut zyada text na likhein.
  • Heading clear aur visible rakhein.
  • Readable font use karein.
  • Background aur text mein proper contrast rakhein.
  • Relevant images use karein.
  • Bullets ka use karein.
  • Unnecessary animations avoid karein.
  • Har slide ka layout consistent rakhein.
  • Spelling check karein.
  • Presentation ko Slide Show mode mein test karein.

Q1. PowerPoint mein Theme kisliye use hoti hai?

A) File delete karne ke liye

B) Presentation ka design change karne ke liye

C) Computer shut down karne ke liye

D) Internet chalane ke liye

Answer: B) Presentation ka design change karne ke liye

Q2. Image insert karne ke liye kaunsa tab use hota hai?

B) Review

C) View

D) Slide Show
