📝 MS Word Lesson 2

Welcome to MS Word Lesson 2. Is lesson mein hum Microsoft Word ke important formatting tools aur practical features ko detail mein seekhenge.

Lesson 1 mein humne MS Word ka introduction, typing, editing, Cut, Copy, Paste, Save aur important keyboard shortcuts seekhe the. Ab hum apne document ko attractive, organized aur professional banana seekhenge.

Lesson Goal: Is lesson ke end tak aap text formatting, paragraph formatting, bullets, numbering, tables, images aur basic page settings ka use samajh jayenge.

1. Text Formatting Kya Hai?

Text formatting ka matlab document ke text ka appearance change karna hota hai. Formatting se document zyada attractive aur easy to read ban jata hai.

Formatting ke examples

  • Font change karna
  • Font size change karna
  • Bold karna
  • Italic karna
  • Underline karna
  • Text color change karna
  • Text alignment change karna
  • Bullets aur numbering lagana

2. Font Kya Hai?

Font text ka design ya style hota hai. MS Word mein different fonts available hote hain.

Example ke liye Arial, Calibri, Times New Roman jaise fonts commonly use kiye ja sakte hain.

Important: Professional document mein readable font use karna better hota hai.

3. Font Change Kaise Karein?

Step 1: Jis text ka font change karna hai us text ko select karein.
Step 2: Home tab par jaayein.
Step 3: Font box par click karein.
Step 4: Apni required font select karein.

Selected text ka font change ho jayega.

4. Font Size

Font size se text ki height ya size change hoti hai. Heading ko usually body text se bada rakha jata hai.

Font Size Change Karne ke Steps

Step 1: Text select karein.
Step 2: Home tab open karein.
Step 3: Font Size box mein required size select karein.

Example:

Heading → 20 ya 24
Normal Text → 11 ya 12

5. Bold, Italic aur Underline

Bold

Bold text ko dark aur prominent banata hai. Important headings ya words ke liye use kiya ja sakta hai.

Shortcut: Ctrl + B

Italic

Italic text ko slightly slanted style mein dikhata hai.

Shortcut: Ctrl + I

Underline

Underline selected text ke neeche line lagata hai.

Shortcut: Ctrl + U

6. Text Color

MS Word mein text ka color change kiya ja sakta hai. Is feature ka use headings ya important information ko highlight karne ke liye kiya ja sakta hai.

Step 1: Text select karein.
Step 2: Home tab mein Font Color option search karein.
Step 3: Required color select karein.

Professional documents mein bahut zyada colors ka use na karein. Simple aur readable design better hota hai.

7. Text Highlight

Text Highlight Color feature ki madad se text ke background ko highlight kiya ja sakta hai.

Iska use important information ko quickly identify karne ke liye kiya ja sakta hai.

8. Text Alignment

Alignment ka use page par text ki position set karne ke liye hota hai.

Alignment Meaning Shortcut
Left Align Text left side par Ctrl + L
Center Align Text center mein Ctrl + E
Right Align Text right side par Ctrl + R
Justify Text dono sides se aligned Ctrl + J

9. Paragraph Formatting

Paragraph formatting se paragraph ki position, spacing aur appearance control ki ja sakti hai.

Paragraph mein kya change kar sakte hain?

  • Alignment
  • Indentation
  • Line spacing
  • Paragraph spacing
  • Bullets
  • Numbering

10. Bullets

Bullets ka use list banane ke liye hota hai jab list ka order important na ho.

Example:

  • Keyboard
  • Mouse
  • Monitor
  • Printer

Bullets option Home tab ke Paragraph section mein mil sakta hai.

11. Numbering

Numbering ka use ordered list banane ke liye hota hai.

Example:

  1. MS Word open karein.
  2. New document banayein.
  3. Text type karein.
  4. Document save karein.

Numbering bhi Home tab ke Paragraph section mein available hoti hai.

12. Line Spacing

Line spacing ka use lines ke beech distance change karne ke liye hota hai.

Proper line spacing se document zyada clean aur readable ban sakta hai.

Step 1: Paragraph select karein.
Step 2: Paragraph settings mein Line Spacing option select karein.
Step 3: Required spacing choose karein.

13. Indentation

Indentation ka use paragraph ko left ya right side se thoda andar move karne ke liye kiya jata hai.

Reports aur structured documents mein indentation useful ho sakta hai.

14. Table Kya Hai?

Table rows aur columns ka collection hota hai. Iska use information ko organized format mein dikhane ke liye kiya jata hai.

Table ke main parts

  • Row
  • Column
  • Cell

Example: Student name, class, roll number aur marks ko table mein easily arrange kiya ja sakta hai.

15. Table Insert Kaise Karein?

Step 1: Insert tab par click karein.
Step 2: Table option par click karein.
Step 3: Required rows aur columns select karein.
Step 4: Table document mein insert ho jayegi.

Example Table

Name Class Subject
Rahul 12 Computer
Aman 12 English
Neha 12 Statistics

16. Image Insert Karna

MS Word document mein images add ki ja sakti hain. Images document ko visually attractive aur informative bana sakti hain.

Step 1: Insert tab open karein.
Step 2: Picture option select karein.
Step 3: Computer mein saved image select karein.
Step 4: Insert button par click karein.

17. Image Resize Karna

Document mein image insert karne ke baad uska size change kiya ja sakta hai.

Image select karne par uske around sizing handles दिखाई दे सकते हैं. In handles ko drag karke image ka size adjust kiya ja sakta hai.

Image ko unnecessarily bahut bada na rakhein. Document ka layout clean aur readable hona chahiye.

18. Page Setup

Page Setup ka use document ke page layout ko control karne ke liye hota hai.

Important Page Settings

  • Page Size
  • Margins
  • Orientation
  • Page Layout

19. Page Orientation

Page orientation document ke page ki direction ko define karti hai.

Portrait

Portrait mein page vertical direction mein hota hai. Letters aur normal documents ke liye ye commonly useful hai.

Landscape

Landscape mein page horizontal direction mein hota hai. Wide tables aur kuch presentations-type documents ke liye useful ho sakta hai.

20. Margins

Margins page ke edges aur document content ke beech ki space hoti hai.

Proper margins document ko professional appearance dene mein help karte hain.

21. Header aur Footer

Header

Header page ke upper area mein hota hai. Ismein document title ya other useful information add ki ja sakti hai.

Footer

Footer page ke lower area mein hota hai. Ismein page number ya other information add ki ja sakti hai.

Header aur Footer ka use reports aur long documents mein especially useful ho sakta hai.

22. Spell Check

MS Word mein spelling mistakes identify karne ke tools available hote hain.

Word kai cases mein incorrect spelling ko mark karta hai, jisse user possible mistake ko identify kar sakta hai.

Spell-check ko blindly follow na karein. Suggested correction ko samajhkar apply karna better hai.

23. Print Preview aur Printing

Document print karne se pehle uska preview check karna useful hota hai.

Step 1: File menu open karein.
Step 2: Print option select karein.
Step 3: Print Preview mein document check karein.
Step 4: Required printer aur settings select karein.
Step 5: Print command select karein.

Keyboard shortcut: Ctrl + P
