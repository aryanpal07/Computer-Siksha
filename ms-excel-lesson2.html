Formula Use Example

ROUND Decimal ko round karne ke liye =ROUND(B2,2)

🔀 IF Function

IF function ka use kisi condition ke according result dikhane ke liye hota hai.

=IF(A1>=33,"PASS","FAIL")

Iska matlab hai:

  • Agar A1 ki value 33 ya usse zyada hai → PASS
  • Agar A1 ki value 33 se kam hai → FAIL
Example: Agar B2 mein marks 75 hain:

=IF(B2>=33,"PASS","FAIL")

Result: PASS

🏆 Grade Formula

Percentage ke according Grade automatically nikala ja sakta hai.

=IF(I2>=90,"A+",IF(I2>=80,"A",IF(I2>=70,"B",IF(I2>=60,"C",IF(I2>=50,"D","E")))))
Percentage Grade
90% or above A+
80% - 89% A
70% - 79% B
60% - 69% C
50% - 59% D
Below 50% E

📌 Marksheet Mein Formulas

1️⃣ Total Marks

=SUM(C2:G2)

C2 se G2 tak ke marks ka total nikalega.

2️⃣ Percentage

=H2/500*100

Yahan 5 subjects hain aur har subject 100 marks ka hai. Total maximum marks = 500.

3️⃣ Result

=IF(MIN(C2:G2)>=33,"PASS","FAIL")

Agar sabhi subjects mein minimum 33 marks hain to PASS, warna FAIL.

4️⃣ Grade

=IF(I2>=90,"A+",IF(I2>=80,"A",IF(I2>=70,"B",IF(I2>=60,"C",IF(I2>=50,"D","E")))))

📊 Average Marks

Average nikalne ke liye AVERAGE function use hota hai.

=AVERAGE(C2:G2)

Example: Agar marks 80, 70, 90, 60, 100 hain to Excel automatically average calculate karega.

🔝 Highest aur Lowest Marks

Highest Marks

=MAX(C2:G2)

Lowest Marks

=MIN(C2:G2)
Exam Tip: MAX ka matlab maximum aur MIN ka matlab minimum.

🔢 COUNT Function

COUNT function kisi range mein numbers ki counting karta hai.

=COUNT(C2:G2)

Agar C2:G2 mein 5 marks hain to result 5 hoga.

🎨 Conditional Formatting

Conditional Formatting ka use condition ke according cells ko highlight karne ke liye kiya jata hai.

Example

  • FAIL → red

💰 Practical 2 - Employee Salary Statement

Excel ka use company mein salary calculation ke liye bhi kiya jata hai. Ab hum ek simple salary statement banayenge.

🧮 Salary Statement Formulas

HRA = Basic Salary ka 20%

=D2 = C2*20%

DA = Basic Salary ka 10%

=E2 = C2*10%

TA = Basic Salary ka 5%

=F2 = C2*5%

Gross Salary

=SUM(C2:F2)

PF = Basic Salary ka 12%

=H2 = C2*12%

Net Salary

=G2-H2
Ye example learning purpose ke liye hai. Real company mein salary components aur deduction rules company aur applicable policies ke according different ho sakte hain.

🎁 Practical 3 - Sales Bonus Calculation

IF function ka ek aur practical example bonus calculation hai.

Employee Sales Bonus Rule Bonus
Rahul 60000 10% 6000
Amit 40000 5% 2000
Neha 25000 0% 0

Formula:

=IF(B2>=50000,B2*10%,IF(B2>=30000,B2*5%,0))

Is formula mein:

  • ₹50,000 ya zyada sales → 10% bonus
  • ₹30,000 se ₹49,999 → 5% bonus
  • ₹30,000 se kam → 0 bonus

❓ MS Excel MCQs

1. Excel mein formula kis symbol se start hota hai?

A) +    B) =    C) #    D) @

Answer: B) =

2. Total ke liye kaunsa function use hota hai?

A) SUM    B) MAX    C) COUNT    D) IF

Answer: A) SUM

3. Average ke liye kaunsa function use hota hai?

A) MIN    B) AVERAGE    C) SUM    D) COUNT

Answer: B) AVERAGE

4. Sabse badi value ke liye kaunsa function hai?

A) MIN    B) COUNT    C) MAX    D) IF

Answer: C) MAX

5. Sabse chhoti value ke liye kaunsa function hai?

A) MIN    B) MAX    C) SUM    D) IF

Answer: A) MIN

6. Condition ke liye kaunsa function use hota hai?

A) SUM    B) IF    C) COUNT    D) MAX

Answer: B) IF

7. Excel mein chart kis tab se insert kiya jata hai?

A) Home    B) Insert    C) View    D) Review

Answer: B) Insert

8. Save shortcut kya hai?

A) Ctrl + P    B) Ctrl + S    C) Ctrl + O    D) Ctrl + N

Answer: B) Ctrl + S

9. Print ka shortcut kya hai?

A) Ctrl + P    B) Ctrl + S    C) Ctrl + C    D) Ctrl + X

Answer: A) Ctrl + P

10. Copy ka shortcut kya hai?

A) Ctrl + X    B) Ctrl + V    C) Ctrl + C    D) Ctrl + Z

Answer: C) Ctrl + C

11. Undo ka shortcut kya hai?

A) Ctrl + Y    B) Ctrl + Z    C) Ctrl + U    D) Ctrl + A

Answer: B) Ctrl + Z

12. Conditional Formatting ka use kisliye hota hai?

A) Computer shutdown

B) Condition ke according cells highlight karne ke liye

C) File delete karne ke liye

D) Printer connect karne ke liye

Answer: B
