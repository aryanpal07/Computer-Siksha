📊 PowerPoint – Lesson 1

Introduction & Basics

1. Microsoft PowerPoint Kya Hai?

Microsoft PowerPoint ek presentation software hai. Iska use information, ideas, data, photos aur other content ko slides ke form mein present karne ke liye kiya jata hai.

PowerPoint ka use school, college, office, business, meetings, training, seminars aur online teaching mein bahut hota hai.

Simple Definition:
PowerPoint ek aisa software hai jisme hum slides banakar information ko attractive aur easy-to-understand way mein present kar sakte hain.

2. PowerPoint ka Use Kahan Hota Hai?

PowerPoint ka use bahut saare areas mein kiya jata hai:

  • School aur college presentations
  • Business presentations
  • Office meetings
  • Project presentation
  • Teaching aur training
  • Seminars
  • Marketing presentations
  • Product presentation
  • Educational videos
  • Online classes
Example: Agar aapko "Computer Basics" ke baare mein students ko samjhana hai, to aap PowerPoint mein alag-alag slides bana sakte hain.

3. Presentation Kya Hai?

Presentation ka matlab hota hai kisi information, idea, topic ya project ko audience ke saamne systematically present karna.

PowerPoint mein presentation ko generally multiple slides mein divide kiya jata hai.

Example:

  1. Title Slide
  2. Introduction
  3. Main Information
  4. Images / Examples
  5. Conclusion
  6. Thank You

4. Slide Kya Hoti Hai?

PowerPoint presentation ka har individual page ek Slide kehlata hai.

Ek presentation mein ek ya multiple slides ho sakti hain.

Example:
Agar presentation mein 10 pages hain, to hum keh sakte hain ki presentation mein 10 slides hain.

5. PowerPoint Kaise Start Karein?

Windows computer mein PowerPoint open karne ke liye:

  1. Start button par click karein.
  2. All Programs par click karein.
  3. Microsoft Office folder open karein.
  4. Microsoft PowerPoint par click karein.
Note: Aapke computer mein PowerPoint ka version alag ho sakta hai, jaise PowerPoint 2007, 2010, 2013, 2016 etc. Basic concepts mostly same rehte hain.

6. PowerPoint ki Main Screen

PowerPoint open karne ke baad screen par kai important areas dikhai dete hain.

  • Title Bar
  • Quick Access Toolbar
  • Ribbon
  • Tabs
  • Slides Pane
  • Slide Area
  • Notes Area
  • Status Bar
  • Zoom Control

7. Title Bar

Title Bar PowerPoint window ke top par hoti hai. Isme current presentation ka naam dikhai deta hai.

Agar file ka naam Presentation1 hai, to title bar mein uska naam dikh sakta hai.

8. Ribbon Kya Hai?

Ribbon PowerPoint ka important part hai jisme different commands aur tools available hote hain.

Ribbon ko different tabs mein divide kiya gaya hai.

Common Tabs:

  • Home
  • Insert
  • Design
  • Transitions
  • Animations
  • Slide Show
  • Review
  • View

9. Home Tab

Home tab mein presentation editing ke basic tools available hote hain.

  • New Slide
  • Font
  • Font Size
  • Bold
  • Italic
  • Underline
  • Text Color
  • Alignment
  • Bullets
  • Numbering

10. New Presentation Kaise Banayein?

New presentation banane ke liye:

  1. PowerPoint open karein.
  2. New option select karein.
  3. Blank Presentation select karein.
  4. New presentation open ho jayegi.
Keyboard Shortcut:
Ctrl + N

11. Title Slide

New presentation open karne par normally first slide title slide hoti hai.

Title slide mein presentation ka main title aur subtitle likha ja sakta hai.

Example:

Title Subtitle
Computer Basics Introduction to Computers

12. New Slide Kaise Add Karein?

Presentation mein additional slide add karne ke liye Home tab mein New Slide option ka use kiya jata hai.

Steps:

  1. Home tab par click karein.
  2. New Slide par click karein.
  3. New slide add ho jayegi.
Shortcut: Ctrl + M

13. Slide Layout Kya Hai?

Slide Layout ka matlab hai slide mein content ko arrange karne ka format.

Common layouts:

  • Title Slide
  • Title and Content
  • Section Header
  • Two Content
  • Comparison
  • Title Only
  • Blank

14. Slide mein Text Kaise Likhein?

Slide mein text add karne ke liye text box ya placeholder mein click karke typing start kar sakte hain.

Example:

My Computer
Computer ek electronic machine hai jo data ko process karke useful information provide karta hai.

15. Text Formatting

PowerPoint mein text ko attractive aur readable banane ke liye formatting ki ja sakti hai.

  • Font Change
  • Font Size Change
  • Bold
  • Italic
  • Underline
  • Text Color
  • Alignment

16. Font Kya Hai?

Font text ka design ya appearance hota hai.

Examples:

  • Arial
  • Calibri
  • Times New Roman
  • Verdana
Presentation mein readable font ka use karna better hota hai.

17. Font Size

Font Size se text ka size chhota ya bada kiya ja sakta hai.

Presentation mein title ko generally body text se bada rakha jata hai.

Content Suggested Size
Title 28–44
Heading 24–32
Normal Text 18–28

18. Bold, Italic aur Underline

Bold: Text ko dark/thick banata hai.

Italic: Text ko thoda slant karta hai.

Underline: Text ke neeche line lagata hai.

Command Shortcut
Bold Ctrl + B
Italic Ctrl + I
Underline Ctrl + U

19. Text Alignment

Text alignment se text ki position change ki ja sakti hai.

  • Left Align
  • Center Align
  • Right Align
  • Justify
Alignment Shortcut
Left Ctrl + L
Center Ctrl + E
Right Ctrl + R
Justify Ctrl + J

20. Bullet Points

Important points ko short aur easy format mein show karne ke liye bullets ka use kiya jata hai.

Example:

  • Computer fast hota hai.
  • Computer accurate results deta hai.
  • Computer large amount of data store kar sakta hai.
  • Computer ka use education mein hota hai.

21. Numbering

Jab steps ko sequence mein batana ho tab numbering ka use kiya jata hai.

Example:

  1. PowerPoint Open Karein
  2. New Presentation Banayein
  3. Text Add Karein
  4. Design Apply Karein
  5. Presentation Save Karein

22. Presentation Save Kaise Karein?

Presentation ko save karna bahut important hai taaki aapka kaam lost na ho.

Steps:

  1. File menu par click karein.
  2. Save option select karein.
  3. File ka naam enter karein.
  4. Location select karein.
  5. Save par click karein.
Shortcut: Ctrl + S

23. Save As Kya Hai?

Save As ka use presentation ko kisi different naam ya different location par save karne ke liye kiya jata hai.

Example:
Agar aapki presentation ka naam "Computer" hai aur aap uski copy "Computer Basics" naam se save karna chahte hain, to Save As ka use kar sakte hain.

24. Existing Presentation Kaise Open Karein?

  1. PowerPoint open karein.
  2. File menu par click karein.
  3. Open option select karein.
  4. Apni presentation file locate karein.
  5. Open par click karein.
Shortcut: Ctrl + O

25. Presentation Close Kaise Karein?

Presentation ko close karne ke liye File menu mein Close option use kiya ja sakta hai.

Agar presentation mein unsaved changes hain, to PowerPoint save karne ke liye pooch sakta hai.

26. Slide Delete Kaise Karein?

Agar presentation mein kisi slide ki zarurat nahi hai to us slide ko delete kiya ja sakta hai.

  1. Left side mein slide select karein.
  2. Keyboard par Delete key press karein.
Delete karne se pehle check kar lein ki correct slide selected hai.

27. Slide Duplicate Karna

Kabhi-kabhi hume ek existing slide ki copy banani hoti hai. Iske liye Duplicate Slide option useful hai.

Isse original slide safe rehti hai aur uski copy par changes kiye ja sakte hain.

28. PowerPoint mein Image ka Basic Use

Presentation ko informative banane ke liye images ka use kiya ja sakta hai.

Image insert karne ke liye generally:

  1. Insert tab open karein.
  2. Picture option select karein.
  3. Computer se image choose karein.
  4. Insert par click karein.
Images ka use topic ko samajhne mein audience ki help kar sakta hai.

30. PowerPoint Presentation Banane ka Basic Process

Ek simple presentation banane ka basic process kuch is tarah hota hai:

  1. Topic choose karein.
  2. PowerPoint open karein.
  3. New presentation banayein.
  4. Title slide banayein.
  5. New slides add karein.
  6. Text add karein.
  7. Images add karein.
  8. Text formatting karein.
  9. Presentation save karein.
  10. Presentation ko check karein.

32. Good Presentation ke Tips

  • Slides ko simple rakhein.
  • Bahut zyada text na likhein.
  • Readable font use karein.
  • Important points ko highlight karein.
  • Relevant images use karein.
  • Har slide ka clear purpose hona chahiye.
  • Presentation ko save karte rahein.
  • Presentation ko final submit karne se pehle check karein.
Tip: Achhi presentation ka goal sirf beautiful slides banana nahi hai. Information ko clearly samjhana bhi important hai.

33. Important Points

  • PowerPoint ek presentation software hai.
  • Presentation multiple slides se milkar ban sakti hai.
  • Slide presentation ka ek individual page hota hai.
  • Ribbon mein different commands available hote hain.
  • Ctrl + M se new slide add ki ja sakti hai.
  • Ctrl + S se presentation save hoti hai.
  • Ctrl + O se presentation open hoti hai.
  • Ctrl + Z se previous action undo kiya ja sakta hai.
  • Images presentation ko informative bana sakti hain.
  • Simple aur clear presentation zyada effective hoti hai.
