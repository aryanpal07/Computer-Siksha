Computer Basics - Lesson 2

Hardware & Software - Complete Basic Guide

📘 1. Hardware Aur Software Kya Hai?

Computer system ko samajhne ke liye Hardware aur Software ko samajhna bahut important hai.

Computer ke kuch parts aise hote hain jinhe hum physically dekh aur touch kar sakte hain. In physical parts ko Hardware kaha jata hai.

Computer ko kaam karne ke instructions aur programs ko Software kaha jata hai.

Simple Trick:

Hardware = Jise hum touch kar sakte hain.

Software = Programs aur instructions.

💻 2. Hardware Kya Hai?

Computer ke physical components ko hardware kaha jata hai. Physical components ka matlab hai computer ke wo parts jinhe hum dekh, touch aur physically handle kar sakte hain.

Hardware ke Examples

  • 🖥️ Monitor
  • ⌨️ Keyboard
  • 🖱️ Mouse
  • 🧠 CPU
  • 🖨️ Printer
  • 🔊 Speakers
  • 💾 Hard Disk
  • 🔌 Power Supply
  • 💿 CD/DVD Drive
  • 📦 Pen Drive
Real Life Example:

Agar aapke paas ek desktop computer hai, to monitor, keyboard, mouse aur CPU ke physical parts hardware hain.

🧩 3. Hardware Ke Main Types

Computer hardware ko unke kaam ke according different categories mein samjha ja sakta hai.

1. Input Hardware

Input hardware ka use computer ko data ya instructions dene ke liye hota hai.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam
  • Joystick

2. Output Hardware

Output hardware processing ke baad computer ka result user tak pahunchata hai.

  • Monitor
  • Printer
  • Speaker
  • Projector
  • Headphones

3. Processing Hardware

Processing hardware computer ke data ko process karne mein important role play karta hai.

  • CPU
  • Processor
  • Motherboard

4. Storage Hardware

Storage hardware ka use data aur files ko store karne ke liye kiya jata hai.

  • Hard Disk
  • SSD
  • Pen Drive
  • Memory Card
  • External Hard Drive

⌨️ 4. Input Devices

Input device wo hardware device hai jiske through user computer ko data ya instructions deta hai.

⌨️ Keyboard

Keyboard computer ka commonly used input device hai. Iska use letters, numbers, symbols aur commands enter karne ke liye hota hai.

🖱️ Mouse

Mouse ek pointing input device hai. Iska use pointer move karne, select karne, click karne aur files ko open karne ke liye kiya jata hai.

🎙️ Microphone

Microphone sound ya voice ko computer mein input karne ke liye use hota hai.

📷 Webcam

Webcam images aur video ko computer mein input karne ke liye use ki ja sakti hai.

📄 Scanner

Scanner documents ya photographs ko digital form mein computer mein enter karne ke liye use hota hai.

🖥️ 5. Output Devices

Output devices computer ke processed result ko user ke saamne present karte hain.

🖥️ Monitor

Monitor screen par text, images, videos aur other information display karta hai.

🖨️ Printer

Printer digital document ya image ko paper par print karne ke liye use hota hai.

🔊 Speaker

Speakers computer se audio output sunne ke liye use hote hain.

📽️ Projector

Projector computer ki screen ya presentation ko large screen par display karne ke liye use hota hai.

🧠 6. CPU - Central Processing Unit

CPU ka full form Central Processing Unit hai. CPU computer ke processing system ka important component hai.

Jab computer ko koi calculation ya instruction process karni hoti hai, to CPU us processing mein important role play karta hai.

Important:

CPU ko commonly computer ka "brain" kaha jata hai, kyunki ye instructions ko process karne mein central role play karta hai.

CPU Ke Important Components

  • ALU - Arithmetic aur logical operations perform karta hai.
  • CU - Control Unit computer operations ko control aur coordinate karti hai.
  • Registers - Processing ke dauran small amount of data temporarily hold karte hain.

💾 7. Computer Memory

Computer memory ka use data aur instructions ko store karne ke liye kiya jata hai.

RAM

RAM ka full form Random Access Memory hai. RAM computer ke currently running programs aur working data ko temporarily hold karti hai.

Computer ko band karne par RAM mein stored temporary information generally retain nahi hoti.

ROM

ROM ka full form Read Only Memory hai. ROM non-volatile memory ka example hai, yani power off hone ke baad bhi information generally retain hoti hai.

💿 8. Storage Devices

Storage devices ka use files aur data ko longer term ke liye store karne mein hota hai.

Hard Disk

Hard Disk computer mein operating system, software, documents, photos aur videos store kar sakti hai.

SSD

SSD ka full form Solid State Drive hai. SSD mein moving mechanical parts nahi hote aur ye commonly fast storage ke liye use hoti hai.

Pen Drive

Pen Drive ek portable storage device hai jise files transfer aur store karne ke liye use kiya jata hai.

Memory Card

Memory cards commonly mobile phones, cameras aur other electronic devices mein storage ke liye use hote hain.

💿 9. Software Kya Hai?

Software programs, instructions aur related data ka collection hota hai jo computer ko specific tasks perform karne mein help karta hai.

Software ko hum physically touch nahi kar sakte, lekin computer par use aur run kar sakte hain.

Software Examples:
  • Windows
  • Microsoft Word
  • Microsoft Excel
  • Microsoft PowerPoint
  • Web Browsers
  • Media Players

🧩 10. Software Ke Types

1. System Software

System software computer hardware ko manage karne aur basic system operations provide karne mein help karta hai.

Operating System system software ka important example hai.

Examples:
  • Windows
  • Linux
  • macOS
  • Android

2. Application Software

Application software users ko specific tasks perform karne mein help karta hai.

Examples:
  • Microsoft Word
  • Microsoft Excel
  • Microsoft PowerPoint
  • Calculator
  • Web Browser
  • Photo Editing Software

🪟 11. Operating System Kya Hai?

Operating System, ya OS, ek important system software hai jo computer ke hardware aur software resources ko manage karta hai aur users ko computer ke saath interact karne ka environment provide karta hai.

Operating System Ke Examples

  • Windows
  • Linux
  • macOS
  • Android
  • iOS

⚖️ 12. Hardware Aur Software Mein Difference

Hardware Software
Hardware physical component hota hai. Software programs aur instructions hote hain.
Hardware ko touch kiya ja sakta hai. Software ko physically touch nahi kiya ja sakta.
Example: Keyboard, Monitor. Example: Windows, MS Word.
Hardware ko physical damage ho sakta hai. Software mein errors ya bugs ho sakte hain.

🔍 13. Hardware Aur Software Ek Saath Kaise Kaam Karte Hain?

Computer ko properly kaam karne ke liye hardware aur software dono ki zaroorat hoti hai.

Jab aap Microsoft Word mein keyboard se typing karte hain:

Keyboard → Hardware

Microsoft Word → Software

Monitor → Hardware

Word document ko display karne wala program → Software

Yaad Rakhein:

Hardware aur Software ek doosre ke complementary hain. Computer system ko useful tasks perform karne ke liye dono ki zaroorat hoti hai.
